# Contributing

## Development workflow

1. Create a feature branch from the target integration branch.
2. Implement scoped changes with tests.
3. Run project checks locally before opening updates.
4. Use semantic commit messages.

## Commit message format

- `feat: add human approval transition`
- `fix: handle MCP tool timeout`
- `refactor: simplify workflow state conversion`
- `docs: update API contract examples`

## Code standards

- Use Python type hints throughout.
- Keep modules small and testable.
- Prefer defensive programming at integration boundaries.
